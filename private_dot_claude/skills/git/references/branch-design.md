# ブランチ設計の判断フロー

変更をブランチ・コミットに分割する際の判断フロー。

## 前提: イシュー・ブランチ・PR・コミットの関係

**基本原則: 1ブランチ = 1PR**。プロジェクト固有のブランチ戦略がある場合はそちらを優先する。

| 概念 | 役割 | 粒度 |
| --- | --- | --- |
| **イシュー** | 何を解決するか（目的の定義） | 独立して完了・検証できる単位 |
| **ブランチ** | 作業の実行単位 | 1PRに対応 |
| **PR** | レビュー・マージの単位 | 1ブランチに対応 |
| **コミット** | 変更の記録単位 | revert 可能な段階的記録 |

イシューとブランチは1対1とは限らない。小〜中規模なら1イシュー = 1ブランチだが、大きいイシューは複数のブランチ・PRに分かれることがある。逆に、複数イシューを1ブランチにまとめるのは避ける。

規模が大きい変更に直面したとき、「ブランチをどう分けるか」から考えるのではなく、**「イシューとして目的を定義し、独立してレビューできるPR単位に分割できないか」** を先に検討する。

## 判断フローチャート

```mermaid
flowchart TD
    Start["未コミットの変更群"] --> Q0{"各変更の目的（イシュー）は<br>明確に定義されているか？"}

    Q0 -->|"いいえ"| A0["先にイシューを定義する<br>「何を解決するか」を明確化"]
    A0 --> Q0
    Q0 -->|"はい"| Q1{"イシューは1つか？"}

    Q1 -->|"はい"| Q2{"変更の規模は？"}
    Q1 -->|"いいえ（複数のイシュー）"| Q3{"イシューごとに<br>revert単位は異なるか？"}

    Q2 -->|"小〜中"| A1["1ブランチ・1〜数コミット"]
    Q2 -->|"大（PRが肥大化）"| QD{"イシュー自体を<br>分割できるか？"}

    QD -->|"はい"| AD["イシューを分割し<br>それぞれにブランチ・PRを作成"]
    QD -->|"いいえ（分割困難）"| QD2{"段階的なPR分割は<br>可能か？"}

    QD2 -->|"はい"| AD2["1イシューを複数PRに<br>段階的にマージ"]
    QD2 -->|"いいえ"| A2["段階的コミットで管理<br>PRの説明で構造を示す"]

    Q3 -->|"はい"| Q4{"それぞれの規模は？"}
    Q3 -->|"いいえ（同時にrevert）"| Q5{"レビュー観点やマージ<br>タイミングは異なるか？"}

    Q4 -->|"大きい変更を含む"| A3["イシュー単位で<br>別ブランチ・PRに分割"]
    Q4 -->|"すべて小さい"| Q5

    Q5 -->|"はい"| A3
    Q5 -->|"いいえ"| A4["同一ブランチ内で<br>コミット分割"]

    style AD2 fill:#cce5ff,stroke:#007bff
    style A3 fill:#cce5ff,stroke:#007bff
```

## 判断の要約

| 条件 | 判断 |
| --- | --- |
| イシューが未定義 | 先にイシューを定義する |
| 1イシュー・規模が小〜中 | 1ブランチ・コミット分割 |
| 1イシュー・規模が大・イシュー分割可能 | イシューを分割し別ブランチ・PR |
| 1イシュー・規模が大・PR分割可能 | 1イシューを複数PRに段階的にマージ |
| 1イシュー・規模が大・分割困難 | 段階的コミットで管理 |
| 複数イシュー・revert単位が違う | イシュー単位で別ブランチ・PR |
| 複数イシュー・revert単位が同じ | レビュー/マージ観点で判断 |

## 分岐元の選択

```mermaid
    BQ1{"変更Aは変更Bに<br>依存しているか？"} -->|"はい"| BA1["Bのブランチから<br>Aのブランチを生やす"]
    BQ1 -->|"いいえ"| BQ2{"共通の前提コミットが<br>あるか？"}
    BQ2 -->|"はい"| BA2["前提コミットから<br>それぞれ生やす"]
    BQ2 -->|"いいえ"| BA3["main/develop から<br>それぞれ生やす"]
```
