# バージョン選定ポリシー

## 新規作成時は安定の最新版を使用する

Git で管理されていないファイルを新規作成する際、外部依存（Docker イメージ、ライブラリ、ランタイム、ツール等）のバージョンを指定する場合は、**安定版（stable）の最新バージョン**を選定する。

- 「新規作成」の判断基準: そのファイルがまだ Git にコミットされていないこと
- RC・beta・alpha 等のプレリリース版は避け、GA（Generally Available）版を使う
- 既に Git 管理されているファイルを変更する場合は、既存のバージョンを尊重し、必要な場合のみアップグレードする
