# dotfiles

個人用の dotfiles を chezmoi で管理しているリポジトリです。参考として公開しているだけのもので、他の環境で動くことは想定していません。

## 前提条件

chezmoi がインストールされていること。インストール方法は公式ドキュメントを参照してください。
